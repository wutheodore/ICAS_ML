# ICAS_ML — Thermal Image Classification

## Project Overview

ICAS_ML is an academic machine learning project focused on binary classification of thermal images into ICAS and non-ICAS categories.

The project explores deep learning approaches for image classification using Python and PyTorch.

## Objectives

- Prepare and organize image datasets for classification.
- Develop and compare baseline CNN and ResNet-based models.
- Train and evaluate image classification models.
- Investigate validation performance and model generalization.
- Analyze experimental results to identify potential overfitting.

## Technologies

- Python
- PyTorch
- Torchvision
- NumPy
- Computer Vision
- Deep Learning

## Project Workflow

1. Prepare and split the dataset into training, validation, and test sets.
2. Load and preprocess thermal images.
3. Train baseline and deep learning models.
4. Evaluate model performance on validation data.
5. Analyze experimental results and generalization.

## Evaluation

The project includes multiple training and evaluation experiments. Model performance should be reported using verified experimental results and clearly identified evaluation datasets.

## Repository Contents

This repository contains selected training scripts, model definitions, dataset preparation utilities, and evaluation tools.

The complete dataset and trained model checkpoints are not necessarily included.
